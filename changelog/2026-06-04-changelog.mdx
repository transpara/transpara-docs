title: Release Notes for Build 5.102.22.697

This release brings several Visual KPI Website improvements for trends, KPI search, and charts, along with a fix for dashboard widget configuration.

{/* truncate */}

## New Features

- **Trend Export (Side by Side):**  
  Added a side-by-side Trend Export mode, in addition to the existing stacked mode.

- **Ad Hoc Trend Pen Names:**  
  Ad hoc trends now have an optional pen name attribute that overrides the lookup name in the legend.

- **Add KPI Search Results to Ad Hoc Trends:**  
  KPI search results can now be added to ad hoc trends, from both the search results and the trend builder.

- **Append KPI Search Results to KPI Lists:**  
  KPI search results can now be appended to a KPI list.

- **KPI Bullet Chart Target Value:**  
  The KPI Bullet chart now shows the target value in the KPI Block.

- **Gauge Chart UI:**  
  Implemented UI improvements for gauge charts.

## Fixes

- **Dashboard Widget Configuration:**  
  Dashboard widget configuration no longer shows batch options on a non-batch dashboard.

**Compatibility:**  
Tested with inmation version v1.78.4.13668.
