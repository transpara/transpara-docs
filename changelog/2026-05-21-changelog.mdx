---
title: Release Notes for Build 5.102.18.693
---

This release improves AVEVA PI and AF Interface Proxy performance and logging, adds full proxy settings to Server Manager, and fixes a high-DPI display issue in Visual KPI Designer.

{/* truncate */}

## New Features

- **AVEVA PI / AF Interface Proxy - Batch Calls:**  
  Improved the use of batch calls for high KPI workloads.

- **AVEVA PI / AF Interface Proxy - Log Controls:**  
  Refined log controls and added adjustable log file sizes.

- **Server Manager - Proxy Settings:**  
  Added support for full proxy settings.

## Fixes

- **Visual KPI Designer:**  
  Resolved display issues on certain monitors with high DPI.

**Compatibility:**  
Tested with inmation version v1.78.4.13668.
