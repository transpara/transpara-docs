This release introduces Transpara Bridge Interfaces, which make existing Visual KPI Interfaces available in the Transpara platform, along with a trend pen table on the website and a new inmation Interface setting.

{/* truncate */}

## New Features

- **inmation Interface:**  
  Added a setting to trend raw values as interpolated.

- **Transpara Bridge Interfaces:**  
  Added the Transpara Bridge Interfaces feature, which automatically makes existing Visual KPI Interfaces available in the new Transpara platform.

- **Trend Pen Table:**  
  A pen table showing pen information and statistics now appears below all trend charts for added detail.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
