This release adds timer-based polling to the AVEVA AF Interface Proxy and fixes rendering and timestamp issues.

{/* truncate */}

## New Features

- **AVEVA AF Interface Proxy - Timer-Based Polling:**  
  Added configurable timer-based polling for AF attribute values that are not subscription-based.

## Fixes

- **Website:**  
  Resolved rendering issues for KPI Blocks positioned below the initially visible portion of a dashboard (below the fold).

- **AVEVA AF Interface Proxy:**  
  Resolved timestamp issues for historical value results.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
