title: Release Notes for Build 5.102.31.706
---

This release adds KPI Block sizes, anchoring, and lasso selection to Image Overlay, and fixes a KPI Block color update issue on dashboards.

{/* truncate */}

## New Features

- **Image Overlay - KPI Block Sizes:**  
  Image Overlay now supports multiple KPI Block sizes.

- **Image Overlay - KPI Block Anchoring:**  
  Image Overlay now supports KPI Block anchoring.

- **Designer - Image Overlay Lasso Selection:**  
  You can now use lasso selection to select objects in Image Overlay.

## Fixes

- **Website:**  
  Fixed an issue where KPI Blocks on dashboards occasionally did not fully update their color on a status change.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
