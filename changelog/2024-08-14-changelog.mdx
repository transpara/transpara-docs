This release introduces the AVEVA PI Interface Proxy and fixes an issue with RCS-based bookmarks in edit mode.

{/* truncate */}

## New Features

- **AVEVA PI Interface Proxy:**  
  Added automatic caching, event subscription, and shared connections to AVEVA PI systems, in addition to the existing connection method.

## Fixes

- **Website - Remote Context Server:**  
  Fixed an issue where RCS-based bookmarks were not consistently rendering correctly in edit mode.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
