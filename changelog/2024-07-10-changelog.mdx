title: Release Notes for Build 5.100.48.644
---

This release introduces the AVEVA AF Interface Proxy, along with AVEVA AF RCS support for bookmark hierarchies and AF Element-based content definitions. Several minor website issues have also been fixed.

{/* truncate */}

## New Features

- **AVEVA AF Interface Proxy:**  
  Enables automatic caching, event subscription, and shared connections to AVEVA AF systems, in addition to the existing connection method.

- **AVEVA AF Interface:**  
  Added the ability to connect directly to an AF System or to an AF Interface Proxy.

- **AVEVA AF RCS - Bookmark Hierarchy:**  
  Added support for the new bookmark hierarchy feature.

- **AVEVA AF RCS - AF Element Definitions:**  
  Added support for using AF Elements to define Profile Groups, Profiles, Dashboards, Dashboard Widgets, and Bookmarks.

- **AVEVA AF RCS - AF Element Organization:**  
  Added support for using AF Elements to organize Profile Groups, Profiles, Dashboards, Widgets, and Bookmarks.

## Fixes

- **AVEVA AF RCS:**  
  Fixed an issue that could lead to orphaned objects due to invalid parent ID assignment.

- **Website:**  
  Implemented minor UI fixes and updates.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
