title: Release Notes for Build 5.102.30.705

This release adds AVEVA AF Event Frame support, including a batch endpoint and virtual dashboards, and fixes issues with trends, XY Plots, and Bridge interfaces.

{/* truncate */}

## New Features

- **AVEVA AF Interface - Event Frames Batch Endpoint:**  
  Added a batch endpoint for Event Frames.

- **Virtual Dashboards for AVEVA AF Event Frames:**  
  The website now supports virtual dashboards for AVEVA AF Event Frames.

## Fixes

- **Website:**  
  Fixed ad hoc multiscale trends not rendering correctly.

- **Website:**  
  Fixed XY Plot reference parameters not rendering correctly.

- **Server Manager:**  
  Fixed name conflict resolution for Bridge interfaces.

**Compatibility:**  
Tested with inmation version v1.94.3.21651.
