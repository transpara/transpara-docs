tStudio is the Transpara Platform's modern, web-based configuration, modeling, and administration environment. It is where teams define and manage the building blocks of real-time operational intelligence, including the operational model, reusable templates, calculation definitions, and the settings that keep deployments consistent across assets, plants, and sites.

What makes tStudio unique is its clear separation of context and logic from the underlying data sources. Instead of embedding tag names, source-system quirks, and one-off fixes inside dashboards or calculations, tStudio lets you define a unified namespace of operational objects with consistent naming, descriptions, units, relationships, and data mappings. That means you can normalize differences across historians, SCADA systems, and sites without forcing changes in the source systems, and you can evolve the model over time without rebuilding everything downstream.

This approach turns configuration into a scalable, governed system rather than a collection of ad hoc edits spread across legacy tools. tStudio is also the connective tissue across the platform. It is where operational context is structured, logic is defined, and governance is applied, so downstream experiences in [tView](/transpara-platform/tview/) and analytics in [tCalc](/transpara-platform/tcalc/) behave consistently and remain efficient to maintain over time. As the environment grows, tStudio helps ensure the platform scales with it, without configuration sprawl or "every site is different" drift.

In practice, this means:

- Modern, browser-based workspace for configuration, modeling, and administration.
- Centralized management of operational models, templates, calculations, and deployment settings.
- Scalable governance to standardize definitions across assets, plants, and sites.
- Designed for onboarding and operating complex industrial environments over time.
- Connects platform building blocks so tView and tCalc deliver consistent outcomes as you scale.

## What tStudio does

tStudio is the control center for configuring and maintaining an operational intelligence system at enterprise scale. It allows you to:

- Build and maintain your semantic model ([tModel](/transpara-platform/getting-started/tmodel)) using a visual, graph-based editor, with support for multi-hierarchy UNS, relationships, attributes, templates, and automated configuration via RCS.
- Define, test, and version advanced calculations using tCalc, including Python, event-driven logic, external AI/ML calls, and templates.
- Design and manage KPI structures, targets, limits, and metadata that will appear in tView.
- Configure dashboards, analysis views, and template-based patterns that promote consistency across sites.
- Manage all data source connections, both Interfaces (read in place) and [Extractors](/transpara-platform/setup/data-extractors/extractors) (ingest into tStore).
- Control deployments, security, authentication, and user roles.
- Monitor the live health of the platform: interfaces, workers, pods, storage, alerts, and API activity.
- Support AI-assisted authoring, modeling, and recommendations as these features roll out.

Everything is no-code and built around operational clarity, not developer workflows.

## Why it matters

tStudio is the primary workspace for configuring and managing Transpara's operational intelligence at scale. It gives engineering and operations teams a structured way to build, govern, and maintain models, calculations, and reusable content so real-time KPIs and dashboards can be delivered consistently across assets, plants, and sites.

Reach for tStudio when you need to:

- Configure and maintain core platform objects (models, attributes, calculations, and related metadata) in one managed environment.
- Build reusable templates and standards so content can be deployed across many similar assets without duplicating work.
- Manage changes safely with governance controls, including review, versioning, and controlled rollout of updates.
- Accelerate project delivery by using structured workflows instead of ad hoc edits across multiple tools.
- Support multi-team collaboration between operations, process engineering, and IT while keeping ownership and responsibilities clear.
- Reduce long-term maintenance by centralizing configuration and minimizing "tribal knowledge" dependencies.
- Ensure consistency in how KPIs, calculations, and asset context are defined across the organization.
- Enable faster troubleshooting and continuous improvement by keeping logic, definitions, and dependencies visible and traceable.

## How it works

tStudio communicates directly with all major components of the Transpara Platform.

### tModel (asset modeling and UNS)

- Graph-based metadata layer that stores relationships, attributes, templates, roles, and events.
- tStudio provides a drag-and-drop, visual editor to define the Unified Namespace (UNS), including multiple hierarchies when needed.
- Supports automated configuration via RCS for ingesting AF models, inmation structures, VMware metadata, and other external sources.

### tCalc (calculations, analytics, event logic)

- Create and manage templates for real-time calculations: simple, complex, event windows, and AI/ML.
- Test execution in-browser with immediate feedback.
- Version calculations safely and track dependencies across the model.

### tStore (time-series and analytics cache)

- Configure extractors, retention policies, indexing, caching behavior, high-frequency ingestion, and health monitoring.
- Determine which data is read in place, cached, or stored permanently, supporting the Virtual Data Lake model.

### Interfaces and extractors

- Manage connections to historians, PLCs, DCS, IoT sensors, SQL databases, APIs, MQTT brokers, IT monitoring tools, and more.
- Configure polling, backfill, ingestion windows, performance tuning, and connectivity health.
- tStudio surfaces status, warnings, and stale-data indicators.

### tView (dashboards, KPIs, analytics)

- Define KPIs, charts, templates, collections, metadata, and relationships that tView will use to auto-generate visualizations.
- Set defaults for visualization behavior, colors, thresholds, grouping rules, and derived analytics.

### Deployment and security

- Configure multi-site, multi-region deployments.
- Manage authentication, SSO/AD/LDAP integration, SSL/TLS, VPN preferences, domain settings, and role-based access.
- View cluster health, including Kubernetes pods, containers, workers, interfaces, and relays.

## Example use cases

Common real-world scenarios where tStudio is used daily:

- Build a multi-site Unified Namespace (UNS) for a utility, refinery, mine, or manufacturing enterprise.
- Import an existing PI AF or inmation model via RCS and apply templates across thousands of assets.
- Configure a combined-cycle plant's KPI templates: OEE, heat rate, equipment performance, and reliability indicators.
- Define event windows for batch, shift, or maintenance intervals and build associated KPIs.
- Manage OPC, MQTT, SQL, historian interfaces and extractors in a hybrid cloud deployment.
- Monitor container health, data freshness, calculation load, and overall platform performance.
- Rapidly deploy a new site or production line using templates and metadata inheritance.
